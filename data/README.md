Bu klasördeki `xu100.csv` dosyası GitHub Actions tarafından hafta içi her akşam otomatik oluşturulur ve güncellenir.

İlk kez oluşturmak için GitHub'da **Actions → BIST 100 verisini güncelle → Run workflow** düğmesine basın ya da bilgisayarınızda şunu çalıştırın:

```bash
python scripts/xu100_guncelle.py
```
